Use case
TiHiY StreamControl Center lets an authenticated creator manage their own
YouTube live activity from one desktop console:
1) retrieve the creator’s live broadcasts and current live state;
2) display live statistics (concurrent viewers and likes);
3) display real-time YouTube Live Chat;
4) send, delete, timeout, and ban in that chat.

We do not use YouTube API Services to scrape third-party channels or to
republish YouTube audiovisual content. Access is limited to the Google
account that completes OAuth.

API methods used by the shipping client
- liveBroadcasts.list (mine=true, part=id,snippet,status)
  — find the creator’s broadcasts, title, privacy, lifeCycleStatus, liveChatId
- liveBroadcasts.update (part=snippet,status)
  — update title, description, scheduled start, and privacy of the creator’s broadcast
- videos.list (part=liveStreamingDetails,statistics)
  — concurrent viewers and likeCount for the active live broadcast
- liveChatMessages.list (part=id,snippet,authorDetails)
  — poll live chat; honor nextPageToken and pollingIntervalMillis
- liveChatMessages.insert
  — send a text message as the authenticated creator
- liveChatMessages.delete
  — delete a selected chat message
- liveChatBans.insert
  — temporary timeout or permanent ban of a chat participant
    identified by authorDetails.channelId

Methods not implemented in this client (not claimed, not shown):
- liveStreams.list
- liveChatMessages.streamList
- liveChatBans.delete (unban)
- liveChatModerators.*
- channels.list

Required Minimum Functionality (live chat / moderation)
- Incoming chat shows the author’s display name (authorDetails.displayName)
  and the message text (snippet.displayMessage).
- Ban / timeout confirmation names the target user and platform
  (YouTube). The API call uses that user’s channelId.
- Delete, timeout, and ban are performed with the OAuth token of the
  signed-in creator. The client status UI shows the connected YouTube
  session.
- User tokens and the OAuth client secret are stored in Windows
  Credential Manager, not in source control.
